**schematize-kotlin** — o piso de Kotlin da casa (Android/KMP).

| Comando | O que faz |
|---|---|
| `/kotlin-help` | esta lista |
| `/kotlin-load` | carrega TODO o corpo normativo (piso, plataforma) e passa a aplicá-lo |
| `/kotlin-review` | roda `scripts/check-kotlin.sh` e revisa o que a máquina não lê |
| `/kotlin-claude` | cria ou mescla o `CLAUDE.md` sempre-on na raiz do repo |
| `/kotlin-cc` · `/kotlin-handoff` | context compact / handoff no archive |

**A fronteira:** no que é de **app** (offline-first, IAM, push, lojas, teste no device), quem manda é
a **`schematize-mobile`**. Aqui é linguagem e toolchain.
